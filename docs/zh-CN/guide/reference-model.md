# 参考模型

`rove sample --model reference` 无需 BEAST 即可运行所提供 20 × 50 XML 的概率模型。
它使用相同的二态 Mk、默认的 Mkv 校正、生灭先验和参数约定。默认选项
`--model strict` 保留先前的单速率类别、严格时钟配置。两个配置都可用
`--conditioning none` 选择不带校正的 Mk。

## 速率与先验

| 组成部分 | 参考配置 |
| --- | --- |
| 性状速率 | 四个 gamma 中点分位数，各占 1/4，归一化至均值一 |
| gamma 形状 | 估计；Exponential(均值=1)，初值 1；参数范围 [0.001, 1000] |
| 分枝速率 | 每条非根分枝一个显式速率；独立 LogNormal(μ=−σ²/2, σ)，初值 0.5；正速率 |
| 时钟标准差 σ | 在对数空间定义并估计；Gamma(形状=5，**尺度**=0.2)，初值 0.2 |
| 突变与时钟乘数 | 均固定为 1 |
| 生灭参数 | λ−μ ~ Uniform(0,1000)，μ/λ ~ Uniform(0,1)，初值分别为 1、0.5 |
| 树先验 | Gernhard，`unscaled`，所有谱系均被采样，以末端数为条件，不以根高为条件 |
| 单系约束 | 通过 `--monophyly` 显式指定；参考命令约束 T1–T19 |

gamma 分位点为 1/8、3/8、5/8、7/8，不是四个概率区间内的平均值。
仅从先验采样时仍使用形状参数的范围限制；与 BEAST 一样，记录的密度不添加
截断归一化常数。Sigma 是**对数速率**的标准差，不是实数空间速率的均值或标准差。
对数正态分布的均值为一，实际分枝速率的均值不会被强制归一化为一。

速率向量含 `2 × 分类单元数 − 2` 个元素。非根节点使用自己的索引；
若最后一个节点不是根，它使用根的索引。这与 BEAST 的显式速率映射相同，
包括子树滑动改变根时的情况。根本身没有分枝速率。类别 `c` 下的遗传距离为
`高度差 × 分枝速率 × 类别速率[c]`。

BEAST 初始化时钟时将 XML 中分枝速率的下限 1e-100 改为零。
因此 Rove 接受所有正的有限速率；零的对数正态密度为零。

## 运行所提供的矩阵

在仓库根目录执行：

```sh
cargo build --release --locked
sh fixtures/reference/20x50/rove.sh runs/reference-1 1
```

脚本运行一千万步，每千步采样一次，并施加 T1–T19 约束。输出目录必须尚不存在。
它等价于[树的采样](./sampler)中的命令加上 `--model reference`。
约束支系为一的支持度来自约束，不是从数据中恢复的结果。

## 提议与输出

采样指南中的九个经典移动保持原有权重。新增三个缩放移动：
`gamma_shape_scale`（权重 0.1）、`clock_sigma_scale`（3）和
`branch_rate_scale`（20，均匀选择一个速率）。初始缩放因子均为 0.5，
都包含缩放移动的 Hastings 比，并使用与其他缩放移动相同的调节规则。

默认调度不使用 ORC 的自适应算子混合、Bactrian 核、分期或树拉伸移动。
Rove 还省略了 XML 中在一维下无作用的突变速率提议。
概率模型一致不意味着链的混合程度或每秒 ESS 相同。

轨迹增加 `gamma_shape`、`gamma_prior`、`clock_sigma`、`clock_rate_prior`、
`clock_sigma_prior` 和 `mean_branch_rate`（无权算术平均值）。
树保留时间枝长，并在每条分枝上添加 `[&rate=...]`；枝长乘速率得到尚未乘以
性状速率的距离。高度相对于固定的时钟乘数，没有日历时间校准。
`run.json` 记录配置、先验、初值、速率映射和最终速率参数。它不是用于恢复运行的检查点。

## 联合提议

另外三个移动可通过 `--weight` 启用，默认权重为零。它们要求松弛时钟，
只改变提议机制，保留似然、先验和参数坐标。

- `node_time_rates` 在较老子节点与父节点之间均匀抽取非根内部节点的高度。
  每条相邻分枝的速率变为 `速率 × 旧时长 / 新时长`，保持分枝距离。
  对数 Hastings 因子是三条分枝的 `ln(旧时长 / 新时长)` 之和。
- `root_time_rates` 将根高度乘以从 `[s, 1/s]` 均匀抽取的 `f`
  （初始 `s = 0.75`），同时补偿两条相邻分枝的速率。
  对数 Hastings 因子在时长项之外还包括 `−ln(f)`。
- `clock_sigma_rates` 用同类乘数缩放 sigma（初始 `s = 0.5`），
  保持各标准化对数速率 `z = (ln(速率) + σ²/2) / σ` 不变。
  对 `d` 个速率，对数 Hastings 因子为
  `(d − 1) ln(f) + Σ ln(新速率 / 旧速率)`。

这些因子修正提议造成的体积变化，不是额外的先验。sigma 移动中速率的
雅可比行列式为 `f^d × Π(新速率 / 旧速率)`，均匀乘数贡献 `1/f`。
逆变换使用 `1/f` 和旧高度。无效值在修改状态前被拒绝。
距离仍经过现有的缓存更新和拒绝恢复流程。

测试检查逆变换、数值雅可比、已知目标分布、根索引变化、精确恢复和后端一致性。
时间与速率联合移动及标准化速率方法已有研究基础，见
[Douglas、Zhang 和 Bouckaert（2021）](https://doi.org/10.1371/journal.pcbi.1008322)；
此实现并未复现整个 ORC 软件包。
[评估协议](https://github.com/getcortexlabs/rove/blob/main/fixtures/validation/SAMPLING-EFFICIENCY.md)
将候选选择与四链验证分开，并预先规定改变默认调度的条件。

## 验证

`tests/rates.rs` 根据高度、gamma 形状、sigma 和显式分枝速率重建两个归档的
BEAST 2.7.8 状态。对数似然的最大绝对差小于 8e-10；各先验组成部分在
2e-12 内一致。类别速率由 Rove 自行计算，而非从 BEAST 导入。

Rove 使用 gamma 分布的[正项级数](https://dlmf.nist.gov/8.7.E1)，
在对数空间以有区间保护的 Newton 步骤求逆。BEAST 使用其旧版 AS91 近似。
归档的 20 个形状参数网格上，类别速率的最大差小于 1.4e-8；因此似然测试的
容差比直接导入速率的测试更宽。指数和 Erlang 分布的闭式表达式提供独立数值检查。

其他测试通过无数据采样检查超先验，并检查不同根的速率映射、每步缓存计算与
重新计算的一致性、拒绝后的恢复、两种后端产生相同样本，以及测试步中没有内存分配。

六个含 20 个分类单元的构造案例中，后验汇总和支系频率满足了预先确定的标准，包括同形性、缺失数据和信号减少的案例。[报告](https://github.com/getcortexlabs/rove/blob/main/benchmarks/inference/2026-10-29/README.md)记录了所有批次、ESS 标准要求的 Mkv 延长批次、运行时间和每秒 ESS。Rove 的经典调度完成五个未校正 Mk 案例所需时间更少，但 BEAST 的对数后验密度和时钟 sigma 每秒 ESS 更高。

后续的[联合提议评估](https://github.com/getcortexlabs/rove/blob/main/benchmarks/sampling/2026-10-29/README.md)
在六个案例中都通过了相同的科学标准。后验密度与 sigma 的每秒 ESS 综合指标为经典
Rove 的 6.63 倍（90% 自举区间：5.89–7.32）。但 gamma 效率在控制案例中降至
0.69，在缺失数据案例中降至 0.66，Mkv 的生灭密度效率降至 0.63。因此预先确定的
回退标准拒绝将候选设为默认：**经典调度仍为默认**，原生应用也保持如此。
三个联合移动可通过 `--weight` 显式启用；报告提供了评估所用权重。在这些案例中，
所有连续统计量的每秒 ESS 中位数均超过已归档的 BEAST ORC 值，但 BEAST 时间
来自旧记录，未在此次重新测量，因此不能据此断言普遍的性能优势。

另有六个固定状态覆盖这些案例。导入相同类别速率时，最大似然差为 1.14e-13；独立生成类别时为 8.16e-8，来自上文所述的分位数近似差异。

## Gamma 提案频率

一项[后续研究](https://github.com/getcortexlabs/rove/blob/main/benchmarks/gamma-mixing/2026-10-30/README.md)发现，在构造的四末端化石定年示例中，gamma 形状参数每 1,100–1,200 步才获得一次提案。将 `gamma_shape_scale` 权重从 0.1 提高到 3，在保持提案与先验不变的情况下，使 gamma ESS 与整组运行墙钟时间之比提高约 22–24 倍。但其他参数成为瓶颈，且一项效率回退未通过运行前确定的标准，因此**默认权重仍为 0.1**，Mac 应用也一样。可通过 `--weight gamma_shape_scale=3` 使用已评估的设置；选择前应检查所有参数及树的诊断结果。这并不意味着整个分析加速了 22–24 倍，也不是 M1 硬件上的测量。

## 配置 sigma 先验

在 Mac 应用的宽松时钟选项下展开 **Clock sigma prior**（界面为英文/葡萄牙文）。
**Shape · Alpha** 和 **Scale · Beta** 默认为 5 和 0.2。Sigma 仍由采样估计；
这些字段指定其先验，不固定 sigma。Gamma 的均值为 shape × scale，方差为 shape × scale²。
修改它们会改变分析假设，不会改变性状 gamma 模型或提议步长。Beta 明确表示尺度，不是速率。

CLI 在 `--model reference` 下接受 `--clock-sigma-shape 2.5 --clock-sigma-scale 0.4`，
适用于 `sample` 和 `marginal`。参数必须为正、有限，且对数归一化项可表示。
严格时钟拒绝这些选项。检查点、仅先验运行、预测及模型比较均保留该先验；链比较要求先验一致。
`run.json` 中的 `clock_sigma_prior_parameters` 记录数值 `shape` 和 `scale`，并保留文字说明。
旧记录按 5 和 0.2 解释。自定义应用设置使用格式 6，防止旧应用忽略设置。
树模型的独立决策见[树先验](./tree-priors)。

## 可选的拓扑与速率联合交换

`--weight narrow_exchange_rates=10` 在现有提议之外启用一项实验性提议。默认权重为零，没有步长调节参数。原生应用中使用 **Advanced sampling → Try joint topology/rate exchange**，初始权重为 10，可继续编辑。选项保存在格式 9 的配置、审查、历史、运行记录和检查点中。目前仅支持无定年的松弛钟；严格钟和定年分析会在采样前被拒绝。这是独立实现的一项提议，并非完整 BEAST ORC 套件。尚未证明形态数据上的速度或混合收益；[#97](https://github.com/getcortexlabs/rove/issues/97) 的比较测量仍然推迟。

设 `G` 为具有内部子节点的内部节点。从这样的 `C(T)` 个节点中均匀选择 `G`，取其较老子节点 `P` 和较年轻子节点 `U`，再以 1/2 概率选择 `P` 的一个子节点 `X`。交换 `X` 和 `U`，保持高度及根不变，并保持两个重接子树的入枝距离：

```text
rX' = rX (hP − hX) / (hG − hX)
rU' = rU (hG − hU) / (hP − hU)
J   = [(hP − hX) / (hG − hX)] [(hG − hU) / (hP − hU)]
log Hastings = log C(T) − log C(T') + log J
```

持续时间和速率必须为正且有限，并满足 `hP > hU`。无效边界或溢出在修改前拒绝。逆映射选择相同的 `G`、`P`，将 `U` 与 `X` 换回；逆向概率为 `1 / (2 C(T'))`，正向为 `1 / (2 C(T))`。连续映射不改变高度，因此雅可比是两个速率缩放因子的乘积。速率仍对应节点索引的入枝，包括根不是最后节点时的特殊槽位。约束与似然/先验拒绝沿用精确恢复路径。保留重接枝距离并不保留似然，因为拓扑改变了。

测试覆盖逆映射、完整数值雅可比、枚举的正反选择、已知均匀拓扑与独立对数正态速率目标、约束拒绝、重新计算与缓存似然、不同根索引、精确检查点回放、原生取消/恢复，以及 portable/ARM 后端样本一致性。这些正确性测试不能替代后验及性能研究。相关方法见 [Douglas、Zhang 与 Bouckaert（2021）](https://doi.org/10.1371/journal.pcbi.1008322)。

## 可选的 Yule 树先验

在设置中选择 **Tree prior → Yule · pure birth**，或在 `sample`、`marginal`
中使用 `--tree-prior yule --birth-rate-upper 1000`。默认仍为出生–死亡模型，
化石定年仍使用 FBD。Yule 假设完全采样、同时代且年龄为零的物种末端，并且
没有灭绝。它拒绝化石定年，不提供节点校准或种群溯祖模型。现生物种、化石末端
及物种内种群样本需要不同的生物学假设。

仅估计出生率 λ，采用适当的 Uniform(0,U) 先验，其对数密度为 −log U，初值为
min(1,U/2)。U 必须为正有限数。树高使用固定单位时钟下的预期变化数，因此 λ
的单位是树高单位的倒数，并非自动解释为每百万年。U=1000 是参考初值，不是
普遍建议。请检查仅先验采样，并使用有科学依据的界限进行敏感性分析。Yule
没有灭绝参数、提议或轨迹统计量。`birth_rate_scale` 支持权重和调节控制。

BEAST 2.7.8 的未缩放约定为
`(n−1) log λ − λ (内部节点高度之和 + 根高度)`，以末端数量为条件，
不以根高或起源为条件，根贡献两次。独立的 Exp(kλ) 等待时间以及从 k(k−1)/2
对中均匀选择合并对，为带标签且按事件排序的树提供归一化乘数
`2^(n−1)/(n−1)!`。该乘数与参数无关，与相同 n 下现有出生–死亡约定一致。
幂后验估计计算 Z(1)/Z(0)，常数因子抵消，所得证据对应于支持域上归一化的
先验。单系约束会限制该域。比较证据时保持矩阵、分类单元和约束一致，并比较
包括 U 及其他先验的完整模型。

模型和界限显示于复核、历史记录及模型比较，并保存在格式 10 的设置、运行记录、
检查点、预测和边际似然估计中。旧版应用会拒绝这些设置。收敛比较不会混合 Yule
与出生–死亡模型，也不会混合不同出生率界限。精确续跑仍要求原始可执行文件。

验证包含来自固定版本 BEAST.base 2.7.8 的 24 个合成固定状态
（`fixtures/validation/yule`）、零灭绝极限、独立模拟等待时间、树高和拓扑频率
（有、无单系约束），以及幂后验证据与数值积分的比较。这些是正确性测试，不是
速度或混合效率的比较声明。
