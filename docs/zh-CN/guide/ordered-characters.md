# 有序性状

有序性状通过相邻状态变化：`0 ↔ 1 ↔ 2`。一条分支仍可以从 `0` 开始、在 `2` 结束，只要经过 `1`。排序限制的是每次变化，而非整条分支的总变化。无序 Mk 则允许任意两个状态间直接变化。

Rove 从 NEXUS 读取这一设置。在 `DATA` 或 `CHARACTERS` 块**之后**添加一个 `ASSUMPTIONS` 块：

```nexus
BEGIN ASSUMPTIONS;
  OPTIONS DEFTYPE=UNORD;
  TYPESET * character_order = ORD: 2-3 5 8;
END;
```

这里第 2、3、5、8 个性状有序，其余无序。索引从一开始。Mac 应用在矩阵及分析确认界面中为每个分区显示 **Ordered** 或 **Unordered**。目前没有单独的排序编辑器。

## 语法与状态字母表

- `DEFTYPE` 接受 `ORD` 或 `UNORD`，默认值为 `UNORD`，适用于类型集中未列出的性状。
- 支持一个带名称的 `TYPESET`，`*` 可省略。无论是否带星号，唯一的类型集都会应用。标准格式接受单个索引、范围、表示最后一个性状的 `.`、`ALL`，以及 `1-7\2` 这样的步长。
- `(STANDARD)` 可省略。`(VECTOR)` 则要求每个性状对应一个 `ORD` 或 `UNORD`，例如三个性状可写成 `TYPESET order (VECTOR) = ORD UNORD ORD;`。
- 多个类型集、重叠指定、命名性状集、其他转换类型、权重及排除项会被拒绝。不支持的假设不会被静默丢弃。其余格式见[读取 NEXUS](./nexus)。

`SYMBOLS` 的声明顺序决定相邻关系；描述性标签不决定顺序。在 `--partitioning observed` 下，有序性状保留从第一个符号到最高已观测或明确可能状态的字母表。因此，若 `SYMBOLS="0123"` 且观测为 `0`、`2`、`3`，有序模型需要**四个**状态，包括未观测的中间状态 `1`。相同的无序观测构成三态模型。

缺失单元格不定义可能状态。已声明的二态字母表始终保留两个状态；其他情况下，推断字母表不足两个状态时会被拒绝。如果更高的未观测状态在生物学上可能存在，使用 `--partitioning declared` 保留完整字母表。Rust 的 `compress_sets` API 也接受显式字母表；有序字母表必须连续且遵循声明顺序。

分区同时按状态数和排序类型分组。即使观测相同，压缩也不会混合有序与无序性状。各分区共享树、时钟和 gamma 形状参数。`rove inspect` 和 `run.json` 记录各分区的排序类型、原始性状索引和状态映射。

## 模型与限制

对于 `k` 个状态，相邻状态间的瞬时速率为 `k / (2(k − 1))`，其他非对角速率为零，每个对角元素为该行流出速率之和的负值。平稳频率均匀分布。这使每个性状在单位分支距离上的预期变化次数为一；二态情况等同于均匀二态 Mk。

Rust 引擎通过正项均匀化、缩放和反复平方计算转移矩阵，并复用工作缓冲区。有序分区采用通用矩阵剪枝路径，目前没有专用的有序 NEON 内核。无序分区继续使用直接 Mk 路径。

有序性状支持不作性状选择的似然以及仅变异性状的 Mkv 条件化，可使用严格或松弛时钟和 gamma 类别。**有序性状尚不支持仅简约信息性状的 Mkparsinf**，运行前会拒绝该设置。条件化必须对应矩阵的收集方式；为绕过错误而修改它会改变统计模型。参见[性状选择](./character-selection)。

检查点保存有序转移矩阵和缓存距离。恢复仍要求相同的引擎构建、输入和设置；此次更改不会迁移旧版本检查点。

## 验证

[验证数据](https://github.com/getcortexlabs/rove/tree/main/fixtures/validation/ordered)包含以 160 位精度独立计算的 36 个矩阵指数、三态解析检查，以及与 BEAST 2.7.8 / MM 1.2.1 的 `Ordinal` 模型进行的 12 个固定状态比较。对数似然的最大绝对差为 `1.82e-9`，涵盖 Mk/Mkv、两种时钟和三种树尺度。测试还检查随机矩阵、中间状态、提案回滚、检查点续跑及准备完成后的内存分配。

这些检查说明所测状态下的数值一致性，并不证明有序分析的后验收敛或速度提升。BEAST 仅用于生成验证参考；运行 Rove 无需安装 BEAST。
