# Mac 预览版

Rove 已有使用 SwiftUI 和 AppKit 构建的首个原生 macOS 工作区。
它可以导入矩阵、准备设置，并运行内置 Rust 引擎，显示实际进度且支持取消。
无需 BEAST 或 Java。

![Rove 原生工作区](/images/macos-preview.png)

## Beta 访问与首次使用

原生 Beta 应用启动后显示 **I have an invitation** 和 **Join the beta list**。
使用已获批准的邮箱申请八位验证码，有效期为十分钟。加入等候名单也需要验证邮箱，
但只登记使用意向，不会授予应用访问权限。邀请由项目团队批准。

确认访问权限后，应用会在介绍之前展示 Rafael 写给 Thiago J. Silva 的感谢信。
点击 **Continue** 后，本机将其标记为已读；退出登录或更新应用都不会再次显示。
感谢信使用应用当前的界面语言。现有用户也会看到一次，但无需重复已完成的介绍。

随后，四步介绍会展示工作区、矩阵、外群和结果。可以跳过介绍、尝试示例，或打开
自己的矩阵；这些操作不会自动启动分析。通过 **Help → Take the Rove tour** 可再次
查看介绍。**Help → What's new in Rove** 提供按版本整理的更新说明和历史记录。
每个有说明的更新只在工作区空闲时自动展示一次，不会紧接首次介绍弹出。
再次打开这些页面会保留现有矩阵及其设置。

访问凭据保存在 macOS 钥匙串中。Rove 在启动时以及运行期间每隔六小时联网验证。
验证成功后，最多可以离线使用七天。邀请过期或被撤销后，不能启动新分析或恢复检查点；
已经运行的分析可以完成。可通过 Help 菜单退出登录。

Cloudflare 验证访问权限，Resend 发送验证码。服务保存邮箱、邀请状态、已确认的使用
意向、界面语言和访问时间。矩阵、树和分析文件保留在 Mac 上。加入名单不等于订阅
新闻邮件。如需从名单中删除，请联系 [Cortex Labs](https://getcortexlabs.com/)。
独立的 Rust CLI 不要求 Beta 访问权限，也不依赖这些网络服务。


## 构建与打开

应用的部署目标为 macOS 14 或更高版本。构建时，请在相应 Xcode 支持的 Mac 上安装 Xcode 26.3 或更高版本及 Rust，
然后从代码仓库根目录运行：

```sh
scripts/build-macos.sh
open build/macos/Rove.app
```

这会构建带有 ad hoc 签名的本地应用，不是经过公证的发行版或安装程序。
界面的深色外观参考 Cortex Labs，支持英语和巴西葡萄牙语。

## 语言与设置

从侧边栏打开 **Settings**，或按 **Command-逗号**。可以跟随 Mac 的语言，
也可以选择英语或巴西葡萄牙语。切换立即生效，并保留已打开的矩阵和分析设置。
偏好保存在本机上。还可以减少动画和侧边栏透明度；系统的辅助功能偏好始终
优先。系统对话框使用 Mac 的语言，引擎的原始诊断信息仍可在 **Technical details** 中查看。

**Rove → About Rove** 显示项目起源、应用版本和贡献者：Rafael Augusto（软件与设计）
以及 Thiago J. Silva（生物学与研究）。窗口使用应用当前语言，并提供网站、指南和源码仓库链接。

## 探索矩阵

按 **Command-O** 打开 NEXUS 文件，将单个文件拖到欢迎界面，或选择
**Try an example**。示例是提供的参考矩阵，含 20 个末端和 50 个性状。

矩阵视图显示分类单元、观测性状、压缩模式和缺失单元格。点击单元格可查看
分类单元、性状和观测值。统计覆盖整个矩阵；可滚动预览最多显示 200 个分类
单元和 120 个性状。应用接受最大 32 MB 的文件。

二态和多态矩阵均可采样。**State partitions** 按观测/可能状态分组，或明确使用
声明字母表。矩阵和复核视图显示各分区数量。
不支持的输入会显示原因。把 gap 当作缺失数据需要明确选择；可能为恒定状态
的性状不能使用 Mkv。

## 准备并运行分析

选择严格时钟或[松弛时钟参考预设](./reference-model)、Mk、Mkv 或 [Mkparsinf](./character-selection)、链长、
采样间隔和随机种子。先验保持引擎默认值。在 Model 中，**Add group** 可选择
必须形成单系群的末端。各组必须相互包含或互不相交。应用不会自动施加任何
约束，包括示例的内群。约束所强制的支持不能视为数据独立恢复的证据。

在 **Outgroup** 中可以选择一个末端，例如 T20。所有末端都保留在分析中：
选择 T20 会要求 T1–T19 构成单系群，T20 位于根分叉的另一侧。
外群末端不是根处的祖先节点。此控件只支持一个外群，默认 **Not selected**。

在 **Additional groups** 中添加分组，或点击铅笔编辑已有分组。勾选只是准备
选择；**Apply group** 才会应用，**Cancel** 会放弃未应用的修改。
未勾选的末端仍参与分析。与外群冲突的分组会阻止运行。清除外群不会删除手动
分组，因此请在核对页面检查 **Applied groups**。

核对页面列出根分叉、实际应用的分组和全部保留末端。运行中的
**Applied analysis setup** 和 History 详情也显示这些信息。保存后重开及
**Use this setup** 会保留选择；导入其他矩阵或 **New analysis** 则从无外群
开始。旧配置保留原有分组，不会自动推断外群。新格式 2 配置需要更新后的应用。
修改配置只用于新分析，不会重定根已有结果。强制分组的支持来自约束本身。

![Mac 应用中的明确外群选择](/images/macos-outgroup.png)

核对设置和分组，选择输出位置，然后点击 **Start analysis** 或按
**Command-Return**。内置 Rust 引擎在本机运行，窗口显示实际完成的步数和已用
时间。运行期间仍可修改界面偏好，但科学配置会锁定。界面不会编造预计完成
时间、ESS 或后验支持。

每次运行创建新文件夹，默认位于 `~/Rove Runs`。**Open folder** 打开保存的配置、
会话记录、进度事件和引擎日志。`results` 子目录包含 `trace.log`、`trees.nexus`
和 `run.json`。运行结束后，Trace、Trees 和 Run record 按钮可在 Finder 中显示
相应文件。**Completed** 表示请求的步数已完成且输出元数据已核验，并不证明
收敛。解释结果前应比较独立运行并评估采样与树的诊断；参见[采样指南](./sampler)。

**Pause analysis** 在下一个采样步保存并停止引擎；链组的所有链一起暂停。在 **History** 中选择运行并点击 **Resume analysis**，卡片显示保存的步数。恢复需要相同的矩阵、设置、Rove 可执行文件和原运行文件夹。

**Cancel analysis** 会请求确认并保留部分输出。关闭应用也会停止引擎。运行中断后，如果存在检查点，History 会提供恢复入口；最后保存之后的步骤会重新计算。没有检查点的旧运行无法恢复。保存的配置用于新的运行，恢复则继续已有运行。

## 保存并重新打开配置

**Save setup** 将原始矩阵路径、SHA-256、设置和明确选择的分组写入 `.rove.json`，
不会复制矩阵或启动运行。**Open Setup**（**Command-Shift-O**）会检查原始矩阵
是否存在且指纹一致，然后恢复配置。缺失或变更的输入会在执行前报告。
开始新运行前请核对恢复的设置。配置文件不是检查点。

**Copy terminal command** 生成使用内置 Rust 引擎的命令，并指定 `~/Rove Runs`
下的新文件夹。命令在执行时读取矩阵。相同的二进制文件、输入、设置、分组和
种子通过应用与 CLI 产生相同的科学样本；应用报告进度不会改变采样。

自动化可使用 `rove sample ... --events-json` 输出带版本号的 JSON 行，事件包括
`started`、`progress`、`completed`、`cancelled` 或 `failed`。
`--expect-input-sha256 HASH` 在创建输出前拒绝已变更的输入；
`--cancel-on-stdin-close` 在所有者关闭输入管道时请求取消。应用使用这些选项。
[协议与进程说明](https://github.com/getcortexlabs/rove/blob/main/apps/macos/README.md#cli-event-protocol-version-1)
定义字段、验证规则和退出码。

## 浏览历史运行

![Rove 历史记录中的已完成、已取消和失败的运行](/images/macos-history.png)

从侧边栏打开 **History**，或按 **Command-Shift-H**。运行按时间从新到旧排列，
显示矩阵、日期、记录的状态、已用时间、模型和种子。可按矩阵名或种子搜索，
也可按状态筛选。选择一条运行可查看已完成与请求的步数、设置、明确选择的
分组及原始输入指纹。文件按钮可在 Finder 中显示现存的输出。

应用会自动发现 `~/Rove Runs` 中以前的应用运行，并在本机记住通过应用选择的
其他输出位置。**Add run folder** 可添加保存在别处的应用运行；请选择包含
`session.json` 或 `setup.rove.json` 的文件夹。**Refresh** 重新检查文件。
应用只读取小型元数据文件，不读取轨迹或树的内容，并在界面线程之外完成读取。

缺失的文件夹、无法读取的记录和不完整的输出会明确标注。没有确认结束的运行
标记为 **Interrupted**，即使已有输出文件。旧记录仍可读取；没有记录的测量值
显示为横线，不作估算。新的尝试在检查输入前保存会话，因此立即取消或启动失败
也能留在历史中；指纹不符时不会产生科学分析输出。

**Use this setup** 会检查原始矩阵并打开保存的设置供核对，不会自动启动分析或
恢复中断的链。运行期间可以浏览 History，再通过 **Current analysis** 返回；
在当前分析结束或取消前，不能复用配置。**Back to workspace**
（**Command-Shift-R**）保留已打开的矩阵和设置。历史功能不会删除输出文件，
也不能证明收敛。

**Compare with other runs** 出现在已完成的运行中。它列出 History 中矩阵、模型、
约束和采样间隔相同、种子不重叠的其他已完成运行，包括链组。选择运行和 burn-in 后，
应用对各链文件夹运行 `rove compare`。报告与链组显示的相同，每条链一列，并保存在
该运行的 `comparisons` 文件夹中。运行之间的一致不代表其中任何一个已收敛。

## 从命令行检查

```sh
target/release/rove inspect fixtures/reference/20x50/matrix.nex
```

命令输出带版本号的 JSON，包含计数、有限的单元格预览、输入哈希，以及分别
说明采样器和 Mkv 适用性的错误。只有该解释合适时才加上 `--gaps missing`。
读取矩阵不会写入分析结果。

## 汇总后验树

![Rove 的后验树汇总](/images/macos-summary.png)

分析完成后，在结果或 History 中选择 **Summarize trees**，设置 burn-in 百分比和节点高度，
再选择 **Create tree summary**。重新打开面板可以查看已保存的汇总。
计算在界面线程之外运行，可以取消。应用不汇总未完成、已取消或中断的分析。

Burn-in 丢弃最前面的 `floor(样本总数 × 百分比 / 100)` 棵树，向下取整。
`STATE_0` 也计为一个样本。默认的 10% 是可修改的建议，并非收敛诊断；
请检查轨迹后再选择。面板显示丢弃和保留的数量。
Burn-in 也可以按样本数给出，对应 `--burnin-samples`。

MCC（最大分支可信度）选择一个**已采样的拓扑**，不是多数规则共识树。
Rove 对每棵保留树的内部支系频率取对数并求和；求和前先对支系排序。
分数完全相同时，选择保留样本中最先出现的候选树。
`posterior` 是包含该支系的保留树所占比例。
由已记录约束强制形成的支系标有 `constrained=true`，其支持度并非从数据中独立恢复的结果。

**Keep selected tree** 保留选中样本的节点高度。
**Common ancestor mean** 使用每个组在**全部**保留树中的最近共同祖先高度的平均值。
枝长是父、子节点高度之差，单位沿用输入树的时间单位。速率仍是独立的乘数；
不推断日历年代，也不转换为速率缩放后的距离。
高度和速率的均值及范围以该支系出现为条件；`CAheight_mean` 和 `CAheight_range` 使用全部保留树。
范围表示观测最小值和最大值，**不是 HPD 或可信区间**。尚未实现高度中位数和 HPD 区间。

每次汇总在分析目录的 `summaries` 下创建新文件夹：

- `mcc.tree`：供 FigTree 使用的单棵有根、带注释的 NEXUS 树。
  在 FigTree 的 Node Labels 中选择 `posterior` 可显示支持度。
- `samples.trees`：全部原始样本的逐字节副本，包含 burn-in，供要求 `.trees` 扩展名的工具使用。
- `summary.json`：输入和可执行文件的哈希、原分析元数据、burn-in、保留数量、选中状态、方法、
  高度策略和 Rove 版本。

按钮会在 Finder 中定位文件。原始 `results/trees.nexus` 和其他分析输出保持不变。
每次汇总都需要容纳另一份原始树文件的磁盘空间。汇总和高支持度不能证明收敛；
还应比较独立运行及采样诊断。

独立 Rust 命令执行同样的计算，不依赖 Java 或 BEAST：

```sh
target/release/rove summarize /path/to/results/trees.nexus \
  --output /path/to/new-summary --burnin-percent 25 --heights ca
```

可改用 `--burnin-samples N` 指定丢弃样本数，或 `--heights keep` 保留高度。
输出目录必须尚不存在。扩展名不改变输入的解释方式。
若输入旁没有 `run.json`，完成状态记为 **unverified**；语法完整的文件并不能证明分析已结束。
若有运行记录，则检查完成状态、样本数量及每个采样间隔。

当前读取器支持 Rove 输出的有根二叉时间树，末端年龄为零或有明确的化石高度注释，并含翻译表，
且 `STATE_` 标识符严格递增。混合分类单元、缺少结尾 `End;`、不完整速率注释或不支持的树形均被拒绝。
定年输出见[化石末端定年](./tip-dating)。不支持多分叉和任意外部 NEXUS 块。
限制为 4,096 个分类单元、512 层嵌套、每条语句 2 MiB，以及一百万个不同支系或支系键
估计占用 128 MiB（先到者为准）。该估计不是进程内存的硬上限。
四次流式遍历只保留支系计数和目标树统计，不在内存中保存全部解析树。

[验证与 Apple silicon 测量](https://github.com/getcortexlabs/rove/blob/main/benchmarks/tree-summary/2026-10-29/README.md)
记录了与固定版本 TreeAnnotator 和外部 NEXUS 读取器的比较。

## 查看带注释的树

![原生 MCC 树查看器](/images/macos-tree.png)

在已完成的结果或 History 中打开 **Summarize trees**，然后在已保存的汇总中选择
**View tree**。独立的原生窗口显示 MCC 结果，不浏览原始样本，也不会把 `STATE_0`
当作最终结果。窗口顶部标明来源运行及保留、丢弃的样本数。**About this summary**
提供 burn-in、节点高度策略、所选来源样本及强制约束的分组。

点击节点或末端可查看支持度、分支长度、高度及可用的速率范围。
展开 **Descendant taxa** 可进入子分支或选择末端。缺失注释显示为 **Unavailable**。
菱形表示受约束的分组，其支持度不是独立证据。经过核验的外群标记为末端，而非根节点。
末端的上下顺序不决定树根位置。

滚动或拖动可平移，捏合手势或缩放按钮可放大，**Fit width** 恢复 100%。
较高的树保持可滚动，以保证标签可读。搜索能找到折叠支系内的分类单元，选择后会展开其祖先。
**Rotate**、**Collapse clade** 和 **Reset display** 仅改变绘图。
画布获得焦点后，上下键遍历可见节点，左键选择父节点，右键进入子节点，空格折叠或展开。
检查器还提供原生导航按钮。指向某个节点或末端会高亮它到根的路径，但不改变选择。这些操作不使用动画。

**Support** 控制支持度标签。短分支或拥挤行上的部分标签会隐藏以避免重叠，但检查器仍提供全部可用值。
长名称在绘图中缩写，在搜索与检查器中完整显示。比例尺和分支使用源数据的时间单位。
速率是单独的乘数；观测范围不是 HPD 区间。

**Export SVG** 导出完整的当前布局，包括旋转及折叠的支系，并附带比例尺、图例和来源信息。
缩放与滚动仅选择屏幕上的可见区域，不裁剪导出的图。SVG 是矢量图；`mcc.tree`、原始样本及运行文件保持不变。
此查看器不包含 PNG 导出、外部树导入或重新定根。

内置命令 `rove inspect-tree /path/to/summary-directory` 在输出版本化显示 JSON 前核验保存的记录及树文件指纹。
读取、布局、搜索和 SVG 生成均在界面线程之外运行。查看器接受单棵 Rove MCC 树，文件不超过 16 MiB，
最多 4,096 个分类单元及 512 层嵌套；上文原始样本读取器的限制保持不变。
汇总依然不能证明收敛。

## 检查采样诊断

![原生 Mac 工作区中的轨迹诊断，预热比例为 25%](/images/macos-diagnostics.png)

在已结束的结果或含有轨迹文件的 History 条目中选择 **Diagnostics**。
窗口列出全部记录参数，首先显示 posterior、likelihood 和 prior。
选择一行即可查看均值、标准差、ESS、95% 等尾区间及轨迹图。
`posterior` 是**对数密度**，不是节点的后验支持度。

修改 **Burn-in (%)** 后按 **Apply**。样本计数和第一个保留状态对应已应用的计算；
尚未应用的修改不会重新标记旧结果。规则与树汇总一致：丢弃 `floor(N × 百分比 / 100)`
个样本，标准运行中的 `STATE_0` 也计入。**Summarize trees with this burn-in**
用已应用的百分比打开汇总面板。两个读取器都会根据运行记录核验采样状态和间隔。

**Whole run** 将丢弃的开头画为灰色并标记 burn-in 边界。**After burn-in**
仅调整绘图范围到保留样本，不改变统计计算。图下方的样本控件支持用键盘查询状态和值。
表格、搜索及控件均有原生键盘导航，图形切换不使用动画。每个参数最多绘制 1,028 个点，
保留各分段的首值、最小值、最大值、末值及 burn-in 边界。
**统计计算使用全部保留样本**，不使用缩减后的绘图数据。

ESS 估计等价于独立样本的信息量，而不是 MCMC 步数。Rove 使用 BEAST 2.7.8
的正自协方差配对约定，滞后小于 2,000；这不是秩归一化的 bulk 或 tail ESS。
常数序列或保留值少于四个时 ESS 不可用。如果正相关延伸到所评估的滞后上限，会明确提示。
在此单链视图中，这些数值不会触发收敛标记或自动停止。可选的多链停止需在探索计划中单独配置。

区间使用线性插值的第 2.5 和 97.5 百分位数（R 类型 7）。它描述保留样本的分布，
**不是 HPD**，也不是均值的蒙特卡洛误差区间。单个样本不提供区间，极短轨迹会被提示。
标量混合、独立运行间的一致性和拓扑收敛是不同的问题：此视图不计算 R-hat 或比较支系。

每次成功计算都会在新目录中保存 `diagnostics/trace-*/diagnostics.json`，包含来源指纹、
burn-in、状态范围、方法、统计量及绘图点。**Calculation record** 在 Finder 中显示该文件。
重新打开时恢复上一次成功使用的百分比，并根据当前文件重新计算。旧报告及原始运行文件保持不变。
读取和计算在界面线程之外运行，可取消，且不停止其他分析。

部分或未核验的运行会被标明。非有限值、列数不一致、采样状态间隔不规则或末行未写完会被拒绝。
如果运行记录声称已完成但轨迹缺少样本，也会拒绝。缺少 `run.json` 时，语法有效的文件不能证明运行结束。
限制为 128 MiB、一百万行、128 个参数及八百万个数值单元格；这些限制不等于进程总内存上限。

独立命令使用同一套 Rust 计算：

```sh
target/release/rove diagnose /path/to/results/trace.log --burnin-percent 25 \
  --output /path/to/new-diagnostics
```

省略 `--output` 可直接输出 JSON，或用 `--burnin-samples N` 指定丢弃数量。
输出目录必须是新目录。运行不需要 Java 或 Tracer。

## 比较独立链

![四条短独立链的比较](/images/macos-chains.png)

在 **Model → The exploration plan** 中选择 **1、2 或 4 条链**。步数适用于每条链。多条链使用不同且已记录的种子同时运行，界面分别显示各链进度。取消操作会关闭整个组。

完成的组及其 History 详情中有 **Do the chains agree?** 面板，展示所有记录统计量的 R-hat、各链 ESS 和支系频率比较。选择一条链即可打开其诊断、汇总树或查看目录。保存的设置保留链数，旧设置仍使用单链。各链输出独立保存，不会把一条链的 burn-in 当作另一条链的延续。

**Stop when diagnostic thresholds are met** 为可选项，默认关闭。它使用 10% burn-in，要求所有记录的标量统计量满足每链 ESS ≥ 200、R-hat ≤ 1.01，每链至少保留 1,000 个样本，且连续两次检查通过。停止步数和原因会被保存。这些标量诊断标准不保证拓扑收敛，仍需检查支系和 trace。CLI 选项和限制见[独立链](./sampler#独立链)。

**Advanced sampling** 折叠在探索计划下方，提供 `rove sample` 的其余选项。**Sample from the priors only** 在不使用性状的情况下运行。开启自动停止后，最小 ESS、最大 R-hat 和检查间隔可以替代引擎的默认值 200、1.01 及其自身的检查节奏。检查点间隔可以按步数设置，而不是默认的约每 30 秒一次。提议方案提供经典默认方案、[松弛时钟](https://github.com/getcortexlabs/rove/blob/main/benchmarks/sampling/2026-10-29/README.md)和[伽马频率](https://github.com/getcortexlabs/rove/blob/main/benchmarks/gamma-mixing/2026-10-30/README.md)报告中评估过的两种方案，以及按移动自定义的权重和初始步长，步长调节可以关闭。每个选项都会在引擎启动前验证，记录在运行记录和 History 中，并以格式 5 保存在配置中；旧版应用会拒绝打开，而不是忽略这些选项继续运行。两种评估过的方案都不作为推荐；报告记录了各自的得失。

## 后验预测检验

History 中已完成的运行包含 **Can the model reproduce the matrix?** 面板，它以选定的 burn-in、重复次数和种子对该运行执行 [`rove predict`](./posterior-prediction)；链组每次只检验一条链。进度和取消与其他工具相同，被取消的检验不留下任何文件。每个已保存的检验列出简约长度、一致性指数和保留指数、模式惊异度以及信息性性状的有效配对数、下尾和上尾比例及其 95% Wilson 区间，以及相等值的数量，与 `predictive.json` 的记录完全一致。检验连同重复矩阵保存在运行的 `predictions` 文件夹中。较小的尾比例标记出需要调查的差异；应用不施加任何阈值。

## 模型比较

同一详情页包含 **Which model explains the matrix better?** 面板，它以选定的幂数、alpha、每个幂的步数、burn-in 和种子，对该运行的模型和约束执行 [`rove marginal`](./model-comparison)。运行的采样间隔、提议权重和步长被沿用；链、检查点和自动停止不可用，对估计的 FBD 参数也不提供估计。进度显示当前的幂和步数；被取消的估计把部分 trace 留在运行文件夹中，但不会列出。每个已保存的估计显示阶石法和路径采样的值及其标准误，以及来自 `marginal.json` 的逐幂表格。当同一矩阵、同一约束和同一缺口策略的其他已完成运行保存了估计时，面板会列出它们与本运行最新估计的差值，以及按平方和开方合并两者的标准误；这两个派生数字是应用唯一自行计算的数字。指南中的注意事项同样适用：估计包含先验，Mk、Mkv 和 Mkparsinf 描述不同的观测过程，带定年的模型只能在定年设置完全相同时比较。
