# 后验预测检验

`rove predict` 检查拟合的模型能否生成具有类似观测数据特征的矩阵。它使用后验树和参数生成新性状，并在**同一棵抽样树**上比较原始矩阵和模拟矩阵。这能检验模型充分性的某些方面，但不能证明收敛，也不是模型为真的概率。[RevBayes 形态学教程](https://revbayes.github.io/tutorials/pps_morpho/)介绍了这一方法。

目前通过 Rust CLI 使用此功能，Mac 应用尚无新界面。无需安装 BEAST、Java、R 或 RevBayes。

## 运行检验

先检查抽样和收敛诊断。然后提供包含 `run.json`、`trace.log` 和 `trees.nexus` 的已完成运行目录，以及该分析使用的原始 NEXUS 文件：

```sh
cargo run --release --bin rove -- predict runs/seed-1 \
  --matrix fixtures/reference/20x50/matrix.nex \
  --output runs/prediction-1 --burnin-percent 25 \
  --replicates 100 --seed 42
```

必须使用实际参与拟合的矩阵，包括应用中所做的分类单元选择。其 SHA-256 必须与运行记录一致。并行分析请选择一条已完成的冷链目录；本命令不会合并多条链。已存在的输出目录、仅从先验抽样的运行、不完整文件、轨迹与树之间不匹配的状态都会被拒绝。源文件复制到新输出目录，原文件保持不变。

预烧期丢弃 `floor(总样本数 × 百分比 / 100)` 行，`STATE_0` 计入总数。每个重复均匀地**有放回**抽取一个保留的后验行，并获得记录在案的模拟种子。同一行被多次抽取是正常的。模拟前会重建所选行的拟合似然，检查拓扑、分支速率和伽马形状参数是否配对正确。

## 模型与观测规则

- 保持每个性状拟合时的状态集和顺序，即使某次模拟中没有出现部分可能状态。有序性状保留中间状态。不能根据模拟观测重新推断状态集。
- 使用拟合的严格时钟或显式松弛分支速率；存在伽马变化时使用拟合的四类别混合。
- 对 Mkv 和 Mkparsinf，先拒绝不符合条件的**完整潜在性状**，再恢复原始缺失值和 gap 掩码。每次尝试都重新抽取伽马类别。掩码后的模拟性状可能看似恒定，即使其潜在性状是可变的；这是预期行为。
- 支持单一状态、缺失值及明确按缺失处理的 gap。不确定状态集合和多态性需要观测生成模型，目前拒绝处理。有序 Mkparsinf 与推断阶段一样仍不受支持。

罕见的条件事件可能超过默认的每性状 100,000 次尝试上限。命令会失败且不发布部分结果；`--max-attempts` 可将上限提高至 10,000,000。通过所属进程管道取消（`--cancel-on-stdin-close`）也会删除部分输出。强制终止进程可能留下不完整目录；只有完整的 `predictive.json` 才表示检验已完成。重复次数、输出规模和工作内存均有上限。

## 读取结果

`predictive.json` 记录模型、输入与构建指纹、预烧期、种子、固定状态集，以及总体和逐性状的尾概率估计。`replicates.jsonl` 将每个矩阵与来源状态及种子关联，并保存配对统计量。`characters.tsv` 保存逐性状配对得分。`matrices/` 包含可读的 NEXUS 模拟矩阵；请按照报告中的 `frozen_character_sets` 解释其模型状态集。

简约性采用每棵后验树上的 Sankoff 得分，不重新搜索最优拓扑。无序变化的代价为一，有序变化为 `|i − j|`。对每个性状，`s` 是该树上的得分，`m` 是最小可能得分，`g` 是最大可能得分。总体一致性指数为 `Σm / Σs`；保留指数为 `(Σg − Σs) / (Σg − Σm)`。分母为零时指数未定义，不记为零。信息性性状计数采用 `g > m`，包含有序代价的影响。缺失观测不产生变化代价。

逐性状拟合还包含配对后验状态下、使用原始缺失掩码的**未条件化模式似然的负对数**。这是差异统计量，不是条件预测密度。性状选择条件在模拟阶段执行。

`p_upper` 是模拟统计量大于或等于观测统计量的有效配对比例；`p_lower` 使用小于或等于。相等值计入两侧，并单独记录。CI/RI 未定义的配对会被计数并排除。较小的尾比例提示需要调查的差异，不应用自动通过或失败阈值。逐性状检验属于探索性分析，没有多重检验校正。

95% Wilson 区间描述的是**以有限的来源经验后验为条件**的模拟误差，不包含 MCMC 误差。增加模拟次数不能修复后验抽样不足；非极端结果也不证明模型充分。

## 验证

测试将四末端树上的模拟模式频率与独立闭式概率比较，覆盖条件化伽马混合和缺失掩码。对祖先状态和四元组拓扑的穷举核验有序与无序性状的简约性、一致性、保留指数及模式似然。CLI 测试覆盖两种时钟、全部支持的条件模式、可复现性、来源文件不匹配、取消和部分结果拒绝。
