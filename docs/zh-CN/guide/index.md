# Rove 是什么？

Rove 是一个用 Rust 编写的系统发育推断项目。它从一个面向形态学数据的似然内核起步，并优先为 ARM CPU 设计。目标是独立推断：不依赖 BEAST，就能从性状矩阵一路运行到树的样本。

这个名字来自探索、漫游与发现路径。

::: info 项目状态
早期。带直接 Mk 路径及其 NEON 内核的似然核心、Mkv 校正、NEXUS 读取器、模式压缩、数值测试和一个最小的独立采样器已经实现。已记录一次 BEAST 2.7.8 参考实验。[松弛时钟参考模型](./reference-model)已实现并通过固定状态检查。后验比较已覆盖六个含 20 个分类单元的构造案例。AVX2 路径和更大规模的跨引擎工作负载仍待完成。工作进展在 [issues](https://github.com/getcortexlabs/rove/issues) 中跟踪。
:::

## 为什么还要一个内核

小的状态空间和短的形态学比对值得作为一类独立的工作负载来度量。

- Mk 有闭式解 `P(t) = e·I + (1 − e)·π`，这使得每个模式的子节点更新只需 O(k)，而不是完整的 O(k²) 矩阵乘法。Rove 的 Mk 核心直接用它做剪枝。
- 针对 ARM 的向量化以及重复计算的复用是候选的优化。它们的价值需要匹配的基准测试来确认，包括初始化和部分更新的开销。
- 记录在案的 BEAST 2.7.8 参考运行使用的是它的 Java 似然核心。这一观察并不能说明每个 BEAST 版本、安装或模型所使用的后端。

Rove 则从数据出发：一种沿位点模式向量化的布局，以及针对形态学家常用模型的快速路径。[设计](./design)页逐一说明这些决定。

## 今天已有什么

引擎是一个没有运行时依赖的 Rust crate。独立的 Swift 包提供[原生 Mac 预览版](./macos-preview)，用于导入矩阵、核对设置、执行分析并显示实时进度。

- `LikelihoodCore`：在位点模式主序布局上的 Felsenstein 剪枝，支持速率类别、可选的逐节点重缩放，以及为采样器准备的节点状态存储/恢复。`LikelihoodCore::mk` 用 Mk 闭式解做剪枝；`LikelihoodCore::new` 为每条分枝乘一个转移矩阵。
- `Backend`：适用于任何目标平台的可移植代码，以及在 aarch64 上用于 Mk 节点更新的 NEON 内核，两者结果相同。见[后端](./kernel#后端)。
- `model::Mk`：带闭式解转移矩阵的 Mk 模型，支持均匀或自定义的状态频率，并会验证这些频率。
- `ascertainment::VariableCharacters`：针对可变性状矩阵的 Mkv 校正，已与两个固定的 BEAST 2.7.8 状态核对。
- `ascertainment::InformativeProbability`：等频率无序 Mk 的缓存 Mkparsinf 条件化，已通过完整模式枚举和 BEAST 2.7.8 验证。参见[性状选择](./character-selection)。
- `reference::Problem`：一个朴素的递归实现，在测试中作为参考保留。
- `rates::GammaRates`, `rates::RelaxedClock`: [Mk + gamma、对数正态速率](./reference-model).
- `mcmc::Sampler` 与 `rove sample` 命令：针对二态和多态性状的 Metropolis–Hastings 采样器，采用分区 Mk 或 Mkv、严格或对数正态松弛时钟和生灭树先验，支持单系约束。见[树的采样](./sampler)。
- `nexus::parse` 与 `data::Matrix::compress`：形态学输入、保留的观测、显式分区和带权重的位点模式。见[读取 NEXUS](./nexus)。
- 属性测试，在 2 到 10 个末端节点、2 到 6 个状态和 1 到 4 个速率类别的随机树上把两种核心都与参考实现比较，包括 10⁻⁹ 到 100 的枝长，以及被接受和被拒绝的变化序列。
- 一个 20 个分类单元、50 个二态性状的合成阳性对照矩阵，以及生成它和降级变体的脚本。

[似然核心](./kernel)页展示如何调用它。[合成矩阵](./fixtures)页描述这个对照。

## 还没有什么

- 多个分区、末端日期、校准和其他树先验。
- AVX2 代码路径。aarch64 以外的目标平台运行可移植代码。
- 与 BEAST 或 BEAGLE 的受控性能基准测试。
- 恢复中断的运行、应用内收敛报告，以及可选的 BEAST 2 或 BEAGLE 适配器。

本站任何地方都没有把这个清单上的内容记载为可用。[路线图](./roadmap)给出先后顺序。

## 作为参考的 BEAST

BEAST 不是依赖。它是验证和基准测试的参考：先在固定状态下比较似然，再比较完整的推断运行。BEAST 2 和 BEAST X 是不同的代码库，其中一个的结果不能说明另一个，因此比较会写明所针对的实现和版本。
