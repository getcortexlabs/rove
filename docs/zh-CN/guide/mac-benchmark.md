# 测试这台 Mac

在侧栏或 Help 菜单中打开 **Benchmark this Mac**，选择 **Run benchmark**。测试使用应用内置的引擎和合成矩阵，无需 BEAST、Java、开发工具或联网。Beta 访问仍遵循正常的离线规则。

为便于比较，请连接电源、关闭低电量模式并退出其他高负载应用。分析运行期间不能启动测试；测试期间也不能启动或恢复分析。可随时取消。关闭 Rove 也会结束测试引擎。

## 测量内容

固定协议 `rove-mac-v1` 使用在 Mk 下模拟的 90 个分类单元和 250 个二态性状，包含恒定性状。模型使用四个 gamma 类别、对数正态松弛时钟，无 ascertainment 筛选。每次测量都以相同种子重新开始，每条链先执行 5,000 次不计时的预热提案，再计时执行 50,000 次提案。算子调节保持启用。

先测量三次**单链**，再测量三次**四条并行链**。后者完成四倍工作量。卡片显示耗时中位数、总提案数每秒以及三个单独时间，保留波动信息。读取、初始化、预热和写入研究结果不计入测量区间；并行区间包含线程调度和等待开销。

这衡量固定工作量，不衡量收敛、科学质量，也不预测用户分析的时长。测试不比较 BEAST。仅比较相同协议和引擎指纹，并分开看待链数。即便芯片相同，电源、温度、后台任务、内存和核心数也会影响耗时。

## 保存和分享

每次测试单独保存在 `~/Library/Application Support/Rove/Benchmarks`。**Previous tests** 打开历史结果，**Saved results** 显示文件夹。取消、中断或无效的测试不能分享。应用不会自动上传结果。

**Share with Cortex Labs** 将选中的完整结果发送至项目的 Cloudflare D1 数据库，包括：

- 六次测量、链数和合成最终状态的校验值。
- Mac 型号标识、芯片、物理/逻辑及可用的性能/能效核心数、内存、macOS、架构和 Rosetta 状态。
- 测试前后的供电来源、低电量模式和热状态类别。
- 应用和引擎版本、可执行文件指纹、后端、协议设置和输入指纹。
- 本次测试的随机 ID 和时间。

结果记录不包含研究矩阵、树、trace、文件路径、设备序列号或 beta 邮箱。上传通过现有 beta 会话授权；服务器使用临时账户/IP 哈希限制请求，和结果分开保存。没有公开排行榜或永久设备标识。结果由客户端报告，并非硬件认证。

上传失败时结果仍保存在 Mac，可重试；重复上传同一记录不会新增数据库条目。如需删除已分享的结果，请提供本地 JSON 中的测试 ID。仅删除本地文件不会删除已分享副本。

[协议和合成输入](https://github.com/getcortexlabs/rove/tree/main/fixtures/benchmarks)随引擎进行版本管理。CLI 的 `rove benchmark` 也会以 JSON 行输出进度和测量，不写入分析输出文件。
