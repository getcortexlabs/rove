## Upgrade exercise

The source was a separate installation of the actual published 0.1.2 build 4,
not a relabeled candidate. The destination was the exact final archive above.
Discovery used a loopback feed with only the enclosure URL changed.

| Check | Result |
| --- | --- |
| Automatic discovery | An overdue check offered 0.1.3 without invoking the manual command. |
| Skip and manual check | Skipping dismissed the offer; a later manual check offered the same version again. |
| Download and installation | The signed archive downloaded and installed; the copy relaunched as build 5. Its signature remained valid, and both app and engine executables matched the packaged candidate. |
| Active analysis | Two installation requests left the temporary example calculation running. Settings showed the pending update with installation disabled. |
| Explicit later installation | Only the temporary test analysis was cancelled, after 12,548,096 steps and 19 seconds. The copy stayed at build 4 until an explicit Settings click installed build 5. |
| Existing data | The original four history entries, history roots, completed onboarding and beta access were retained. |
| Release experience | The 0.1.3 highlights appeared after upgrade. The original thank-you letter opened twice from Help. |
| Cleanup | Only the temporary run's history entry was removed; its files were retained in the isolated test directory. Pre-test updater preferences and release acknowledgment were restored, and the loopback server was stopped. |

This was an updater correctness exercise, not a comparative performance study.
Old-engine checkpoints still require the matching previous app; retained History
does not imply checkpoint compatibility across engine versions.

## Candidate validation

Twenty-four targeted native tests passed locally, covering launch state, update
configuration/signatures/deferral, advanced settings, DNA and combined execution,
and evidence assessment. Documentation build, CLI/native parity (12 commands,
45 options), three update-publishing tests and three notification-client tests
also passed. English and Brazilian Portuguese release previews were inspected.
The full native and Rust suites passed in candidate CI. No comparative
performance measurements or beta test emails were run for this release.
